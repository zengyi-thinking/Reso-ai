# 产品与工程路线图

## Stage 0 — Foundation（本轮）

Repository Audit、Monorepo、Contracts、Database Skeleton、Mock Agent、Agent Service Skeleton、Web v0、CI、Local Development、Docs。

## Stage 1 — First Closed Loop

Journey、Persona V1、Agent Birth、Agent Chat、Message persistence、Memory/Reflection Candidate、Persona Patch confirmation、Persona V1.1。

## Stage 2 — Agent Quality

Long-term Memory、Correction Memory、Relationship Memory、Context retrieval、Agent Lab replay、deterministic Eval 和质量指标。

## Stage 3 — Social Agent

Reso World、Agent Card、Social Mission、bounded Agent ↔ Agent、Disclosure、Recommendation Candidate。

## Stage 4 — Human Relationship

双方 Consent、Human Chat、Agent Assist、Relationship Timeline 与关系 Reflection。

每一阶段只有在上一阶段的用户可观察闭环、隐私边界和评估通过后才推进。

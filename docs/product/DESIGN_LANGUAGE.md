# UI Design Language

## 感受

温暖、治愈、手绘、绘本、天空、群岛、云、木桥、旅行、手记、成长。目标是“进入一个世界”。

## 基线

- 色彩：奶油色背景、天空蓝主色、浅绿与浅橙点缀、低饱和深青灰正文。
- 形状：18–28px 轻微不规则圆角，柔和阴影，不制造卡片海。
- 排版：标题偏人文/绘本，正文清晰，避免传统企业 Dashboard 密度。
- 动效：缓慢漂浮、呼吸和按压反馈；180–480ms；支持 `prefers-reduced-motion`。
- 可用性：Mobile First、44px 触控目标、清晰 focus、loading/empty/error/disabled 状态。

禁止黑紫赛博、霓虹、Tinder 滑卡、传统 SaaS、无意义渐变、emoji 图标替代和伪造插画。正式资产缺失时使用明确占位并记录来源需求。

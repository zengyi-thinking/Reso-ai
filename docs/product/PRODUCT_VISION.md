# Reso.AI 产品愿景

Reso.AI 的核心不是堆叠 AI 功能，而是建立一个随用户人生经历持续演进的关系智能系统。

## 五个差异化

1. **Living Persona**：不是静态标签，而是有证据、置信度、版本和用户确认的当前理解。
2. **Long-term Understanding**：Reso Agent 跨时间保持连续理解，并尊重纠正。
3. **Relationship Memory**：关系是一等公民，拥有事件、阶段和时间线。
4. **World + Story**：用户进入天空、群岛、旅行和手记构成的世界，而非 AI Dashboard。
5. **Scaffold toward Real Human Relationships**：Agent 帮助真人表达与建立联系，关系自然成立后主动退到旁边。

## 价值时间线

- 第 1 天：体验有趣，而且理解有依据。
- 第 1 周：Agent 开始记得我，也记得我纠正过什么。
- 第 1 个月：在明确授权下探索值得认识的人。
- 第 3 个月：沉淀关系经历和成长。
- 第 1 年：保存过去一年的我，同时允许我改变。

优先 Meaningful Connection Rate、Felt Understood、Persona Correction Rate、Relationship Continuation 与 Scaffold Behavior，而非单纯聊天时长、消息数或在线时长。

# 用户主流程

```text
扫码 / Link
  → Welcome
  → 约 8 轮 Journey
  → Persona Draft
  → 用户修改 / 补充
  → 注册与 Persona V1
  → Agent Birth
  → Agent Chat
  → Memory / Reflection Candidate
  → Persona Patch Candidate
  → 用户确认
  → Persona V1.1
```

Stage 3 以后才加入 Explore/Reso World、Social Mission、Agent ↔ Agent、Recommendation、双方 Consent 与 Human ↔ Human。

关键体验要求：Journey 选择不直接成为人格结论；所有 Draft/Patch 可解释和修改；Proxy 行动前明确展示范围、披露级别、预算和停止条件。
